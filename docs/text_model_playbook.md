# 텍스트 모델 구축 기준서

> 텍스트 분류 모델을 만들 때 쓰는 계획 순서표입니다.
> 코드는 PyTorch, scikit-learn, gensim 기준의 **짧은 예시**입니다. 전체 코드가 아니라 "이런 모양이다" 수준으로 봅니다.
> 표 안의 `<br>`은 줄바꿈입니다. VS Code 미리보기(Cmd+Shift+V) 등 마크다운 미리보기에서 줄이 나뉘어 보입니다.

**핵심 원칙 한 줄**: 규칙은 train/val/test 모두에 똑같이 **적용**하고, 사전·임베딩·`max_len`처럼 데이터에서 **배우는 것**은 train으로만 만듭니다.

| 계획순서 | 설명 | 코드 예시 | 일부 개념 |
|---|---|---|---|
| **0. 환경 설정, 시드** | 라이브러리를 불러오고 난수 시드를 고정합니다. 노트북 **맨 위**에서 한 번 정의합니다. | `import random, numpy as np, torch`<br>`def seed_everything(s=42): random.seed(s); np.random.seed(s); torch.manual_seed(s)`<br>`seed_everything(42)`<br>`device = 'cuda' if torch.cuda.is_available() else 'cpu'` | • 시드 값은 하나(42)지만 호출은 여러 번(맨 위, **모델 생성 직전**)<br>• 시드가 영향을 주는 곳: 가중치 초기값, Dropout, 데이터 섞기(shuffle)<br>• gensim, 데이터 분할(`random_state`)은 **자체 시드**를 따로 둠<br>• "완전히 같다"가 아니라 "거의 같다"가 목표 |
| **1. 문제 정의** | 입력, 출력, 문제 유형, 평가 기준을 한 문장으로 정합니다. | (코드 없음)<br>예: 입력=뉴스 글, 출력=20개 카테고리 중 하나, 지표=정확도 + macro F1 | • 분류 유형: 이진 / 다중 클래스 / 다중 레이블<br>• 클래스가 불균형하면 정확도만 보면 속으므로 정밀도, 재현율, F1을 같이 봄<br>• 평가 지표는 **처음에** 정해둠 |
| **2. 데이터 수집** | 데이터를 불러오고 **형태와 구성**을 한 번 확인합니다. | `from sklearn.datasets import fetch_20newsgroups`<br>`data = fetch_20newsgroups(subset='all', remove=('headers','footers','quotes'))`<br>`data.keys(); data.target_names; len(data.data)`<br>`df = pd.read_csv('file.csv')  # 표 형태일 때` | • 형태: Bunch(이름표 서랍장) / DataFrame / 리스트. 형태에 따라 꺼내는 법이 다름<br>• 불러오는 **옵션**(`subset`, `remove`)도 기록해야 비교가 됨<br>• 출처, 라이선스, 공식 분할 유무 확인<br>• 처음에는 샘플 1~2건을 직접 읽어봄 |
| **3. 데이터 분할** | train / val / test로 나눕니다. **EDA, 정제보다 먼저** 합니다. | `train_val_x, test_x, train_val_y, test_y = train_test_split(texts, labels, test_size=0.2, random_state=42, stratify=labels)`<br>`train_x, val_x, train_y, val_y = train_test_split(train_val_x, train_val_y, test_size=0.25, random_state=42, stratify=train_val_y)`<br>`len(train_x), len(val_x), len(test_x)` | • **데이터 누수**: test 정보가 학습에 스며들면 점수가 부풀어짐<br>• `train_test_split`은 한 번에 2덩어리만 나누므로 **두 번 호출**. test를 먼저 떼어냄<br>• `stratify`: 클래스 비율 유지<br>• 6:2:2 예시. 시계열이면 **시간순** 분할<br>• 나눈 뒤 개수와 비율을 출력해서 확인 |
| **4. EDA (정제 전)** | **train 기준**으로 원본 텍스트의 성격을 파악합니다. | `pd.Series(train_y).value_counts().sort_index().plot(kind='bar')`<br>`lens = [len(t.split()) for t in train_x]; np.percentile(lens, 95)`<br>`from collections import Counter`<br>`Counter(w for t in train_x for w in t.split()).most_common(20)`<br>`len(train_x) - len(set(train_x))  # 중복 수`<br>`set(train_x) & set(test_x)  # 분할 간 중복` | • 클래스 분포(불균형 여부), 문서 길이 분포, 단어 빈도, 한 번만 나온 희귀 단어 비율, 어휘 크기<br>• 빈 문서, 중복 문서, 특수문자·숫자·이메일 섞임<br>• n-gram: 연속된 n개 단어 묶음 빈도<br>• 워드클라우드: 빈도 시각화(보조 용도)<br>• 단어 빈도 ≠ TF-IDF. TF-IDF는 "이 문서에서 얼마나 특징적인가"<br>• 결과마다 **"→ 실험 후보"**를 한 줄 적어둠 |
| **5. 정제 (클리닝)** | 텍스트의 잡음을 줄이는 **규칙**을 정하고 train/val/test에 **똑같이** 적용합니다. | `import re`<br>`def clean_text(t): t = re.sub(r'[^a-z\s]', ' ', t.lower()); return re.sub(r'\s+', ' ', t).strip()`<br>`import nltk; from nltk.corpus import stopwords`<br>`stop = set(stopwords.words('english'))  # nltk 데이터 다운로드 필요` | • 규칙 적용은 모두 동일, **통계로 배우는 것**(불용어 선정, 어휘 사전)은 train으로만<br>• 소문자 변환, 특수문자·숫자 제거, 불용어 제거<br>• 영어: 어간 추출(stemming)/표제어 추출(lemmatization). 한국어: 형태소 분석(Kiwi 등)<br>• **사전학습 모델(BERT 등)은 정제하지 않은 원문**을 넣는 게 보통<br>• 정제 방식이 바뀌면 길이, 어휘, `max_len`도 다시 확인 |
| **6. 토큰화** | 문장을 모델이 다룰 단위(토큰)로 자릅니다. 3종 임베딩이 **같은 결과**를 공유합니다. | `from nltk.tokenize import word_tokenize  # punkt 등 데이터 필요`<br>`train_tokens = [word_tokenize(t) for t in train_x]`<br>`val_tokens = [word_tokenize(t) for t in val_x]`<br>`test_tokens = [word_tokenize(t) for t in test_x]` | • 단위: 단어 / 형태소 / 서브워드(BPE, SentencePiece, WordPiece)<br>• **val, test도 빠뜨리지 말고** 같은 함수로 변환<br>• 사전학습 모델은 **자기 전용 토크나이저**를 써야 함<br>• 토큰화를 바꾸면 임베딩 재학습, 사전/행렬 재생성, `max_len` 재결정, Dataset 내부 토큰화까지 연쇄 변경<br>• 비교 실험에서는 모델마다 토큰화를 다르게 하지 않음 |
| **7. EDA (정제 후)** | 정제와 토큰화 결과를 확인하고 **`max_len`**을 정합니다. | `lens = [len(t) for t in train_tokens]`<br>`max_len = int(np.percentile(lens, 95))`<br>`vocab = set(w for t in train_tokens for w in t)`<br>`val_words = [w for t in val_tokens for w in t]`<br>`sum(w not in vocab for w in val_words) / len(val_words)  # OOV 비율` | • `max_len`: 보통 길이의 95분위수. 너무 긴 5%는 잘라냄<br>• **OOV**: 사전에 없는 단어. 비율이 높으면 임베딩 선택이나 정제를 재검토<br>• 정제 전후 비교: 길이, 어휘 수, 예시 몇 건<br>• 정제 후 **빈 문서**가 생겼는지 확인<br>• 값은 **train 기준**으로만 정함 |
| **8. 공통 통일 항목** | 모델끼리 **공정하게 비교**하려고 임베딩 외 조건을 고정하고 기록합니다. | `CFG = dict(seed=42, batch_size=32, max_len=280, lr=5e-3, epochs=10)` | • 비교 실험은 **한 번에 하나만** 바꿔야 원인을 알 수 있음<br>• 통일할 값: 시드, 분할, 배치, `max_len`, 학습률, 에폭, 임베딩 차원<br>• 통일이 불가능한 값(예: GloVe의 정해진 차원)은 **한계로 기록**<br>• 모델 구조는 별도 단계에서 관리해도 됨 |
| **9. 벡터화 (임베딩)** | 토큰을 숫자 벡터로 바꿀 방법을 만듭니다. **임베딩마다 (사전, 행렬) 한 쌍**을 만듭니다. | `from gensim.models import Word2Vec`<br>`w2v = Word2Vec(sentences=train_tokens, vector_size=200, window=5, min_count=1, sg=1, seed=42, workers=1)`<br>`word2idx = {w: i+1 for i, w in enumerate(w2v.wv.index_to_key)}`<br>`matrix = np.zeros((len(word2idx)+1, 200))`<br>`for w, i in word2idx.items(): matrix[i] = w2v.wv[w]`<br>`emb = {}  # GloVe 파일 읽기`<br>`for line in open(path, encoding='utf-8'): v = line.split(); emb[v[0]] = np.asarray(v[1:], dtype='float32')`<br>`TfidfVectorizer(min_df=2).fit_transform(train_x)  # 고전 방식`<br>`SentenceTransformer('모델명').encode(texts)  # 사전학습 문장 임베딩` | • 임베딩: 비슷한 문맥에 나오는 단어를 가까운 벡터로<br>• **Word2Vec**: skip-gram(중심→주변 예측), CBOW(주변→중심 예측)<br>• **FastText**: 글자 조각(n-gram)을 써서 처음 보는 단어도 벡터를 만들 수 있음(단, 사전에 없는 단어를 0으로 처리하는 파이프라인이면 이 장점을 못 씀)<br>• **GloVe**: 동시 등장 통계 기반, 보통 **사전학습 파일**을 불러서 씀<br>• 직접 학습은 **train으로만**<br>• 사전학습 vs 직접 학습은 **학습 데이터 규모**가 달라서 점수 차이가 알고리즘 때문인지 단정하기 어려움<br>• 사전과 행렬은 반드시 **같은 임베딩의 짝**<br>• 0번은 패딩(PAD)용, OOV(UNK)와 분리할지는 선택 |
| **10. 입력 데이터 구성** | 토큰을 번호로 바꾸고 길이를 맞춰 배치로 묶습니다. | `class TextDS(Dataset):  # __init__, __len__, __getitem__`<br>`ids = [word2idx.get(w, 0) for w in tokens][:max_len]`<br>`ids += [0] * (max_len - len(ids))`<br>`DataLoader(train_ds, batch_size=32, shuffle=True)`<br>`DataLoader(val_ds, batch_size=32, shuffle=False)` | • 정수 인코딩 → 패딩/자르기 → 정답과 짝짓기<br>• **Dataset**: 한 건을 꺼내는 규칙, **DataLoader**: 여러 건을 묶는 배달부<br>• **shuffle은 train만** True. val/test는 False<br>• Dataset은 train/val/test 3개<br>• 사전과 `max_len`은 train 기준, val/test는 **적용만**<br>• 트랜스포머류는 패딩을 가리는 **attention mask**도 함께 씀 |
| **11. 모델 구현** | 분류 모델의 구조를 클래스로 정의합니다. 정의만 하고 실행은 뒤에서 합니다. | `nn.Embedding.from_pretrained(torch.tensor(matrix, dtype=torch.float), freeze=False)`<br>`nn.LSTM(emb_dim, hidden, num_layers=2, batch_first=True, bidirectional=True, dropout=0.5)`<br>`nn.Linear(hidden*2, num_classes)`<br>`# forward: 임베딩 → LSTM → 요약 → Linear → 점수` | • `__init__`은 부품 준비, `forward`는 부품 연결<br>• 모양 변화: (B, L) → (B, L, E) → (B, L, 2H) → (B, 클래스 수)<br>• **양방향**이면 두 방향을 모두 쓰는지 확인(이어 붙이기 또는 평균 풀링)<br>• 마지막에 softmax를 따로 안 넣음(`CrossEntropyLoss`가 안에서 처리)<br>• `freeze=False`면 임베딩도 학습 중에 같이 바뀜<br>• `hidden_dim`, `dropout`, 층 수는 하이퍼파라미터<br>• 먼저 간단한 기준 모델(TF-IDF + 로지스틱 회귀)을 두면 비교 기준이 됨 |
| **12. 학습 및 평가** | 모델을 만들고 학습하며 **val로 점검**합니다. test는 쓰지 않습니다. | `seed_everything(42)  # 모델 생성 직전`<br>`model = Clf(...).to(device); loss_fn = nn.CrossEntropyLoss()`<br>`opt = torch.optim.Adam(model.parameters(), lr=5e-3)`<br>`from tqdm import tqdm  # for x, y in tqdm(loader):`<br>`opt.zero_grad(); loss = loss_fn(model(x), y); loss.backward(); opt.step()`<br>`model.eval()  # 평가 시`<br>`with torch.no_grad(): pred = model(x).argmax(1)`<br>`if va_loss < best: best = va_loss; state = copy.deepcopy(model.state_dict())`<br>`from sklearn.metrics import classification_report`<br>`print(classification_report(y_true, y_pred, target_names=names, digits=3))` | • **순전파**: 예측, **역전파**: 오차의 책임(기울기) 계산, `step`: 가중치 수정<br>• 에폭: train을 한 바퀴 도는 횟수, 배치: 한 번에 넣는 묶음<br>• `train()`은 Dropout 켬, `eval()`은 끔<br>• **과적합**: train loss는 줄고 val loss는 다시 오름. val loss 최저 에폭의 가중치를 저장<br>• 정확도, 정밀도, 재현율, F1. 다중 분류는 평균 방식이 필요: **macro**(클래스 평균), **weighted**(문서 수 가중)<br>• 튜닝과 선택은 **val**로만 |
| **13. 결과 기록** | 같은 조건으로 돌린 결과를 **비교표**에 옮겨 적습니다. | `rows.append({'임베딩': name, '최소 val loss': .., '최고 val 정확도': .., '최적 에폭': .., 'macro F1': ..})`<br>`pd.DataFrame(rows).round(3)` | • 셀 출력은 다시 실행하면 사라지니 **표에 옮겨** 적음<br>• 1차는 "임베딩만 다른" 비교표, 2차부터는 "바꾼 것 한 줄씩 쌓는" 실험 기록표<br>• 조건(시드, 배치, `max_len`, 차원 차이 등)을 표 위에 함께 적음 |
| **14. 오류 분석 (선택)** | 점수 뒤에 **어디서 틀렸는지** 확인합니다. | `from sklearn.metrics import confusion_matrix`<br>`cm = confusion_matrix(y_true, y_pred)`<br>`wrong = [i for i, (a, b) in enumerate(zip(y_true, y_pred)) if a != b]` | • 혼동행렬: 어떤 클래스끼리 헷갈리는지<br>• 오분류 문서를 몇 건 직접 읽어 원인(너무 짧음, 주제 겹침, 노이즈) 확인<br>• 여기서 나온 가설이 **다음 실험의 근거**가 됨 |
| **15. 실험 계획과 반복** | 1차 결과를 보고 **바꿀 것을 한 개씩** 설계해서 돌립니다. | `for lr in [5e-3, 1e-3]: seed_everything(42); run(lr=lr)`<br>(바꾼 것 하나만 바꾸고 나머지는 `CFG` 그대로) | • 하이퍼파라미터: 학습 전에 **사람이 정하는 값**(임베딩 차원, `window`, `min_count`, `max_len`, 학습률, 에폭, `hidden_dim`, `dropout`, `freeze`, 토큰화 방식)<br>• 파라미터: 모델이 학습하며 스스로 바꾸는 값(가중치)<br>• 각 실험에 **"이유(EDA 근거)"와 "기대하는 변화"**를 적음<br>• 시드 고정, 같은 val로 비교<br>• 차이가 작으면 "효과 없음"이 아니라 "이 조건에서는 작았다"로 읽음 |
| **16. 최종 선발과 test 평가** | 가장 좋은 설정을 하나 정하고 **test로 딱 한 번** 평가합니다. | `model.load_state_dict(best_state)`<br>`evaluate(model, test_loader)  # 딱 1회` | • test를 보고 설정을 다시 고르면 누수가 됨<br>• 선발 기준(예: val macro F1)은 **미리** 정해둠<br>• 결과와 함께 **한계**(조건 차이, 데이터 규모 차이)와 재현 정보(시드, 설정, 분할)를 기록 |

## 쓸 때 참고

- **한국어 텍스트일 때** 달라지는 곳은 5번(형태소 분석)과 6번(형태소 또는 서브워드 토큰화)입니다. 영어 전용 사전학습 모델(GloVe 등)은 한국어에 맞지 않으니 언어에 맞는 임베딩을 골라야 합니다.
- **사전학습 트랜스포머를 미세조정할 때**는 5~6번을 모델 전용 토크나이저로 대체하고, 9~11번이 "모델 불러오기"로 단순해집니다.
- 코드 예시는 함수와 옵션 이름이 라이브러리 버전에 따라 달라질 수 있으니, 실제로 쓸 때 공식 문서로 한 번 확인합니다.
